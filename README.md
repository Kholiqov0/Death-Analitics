# Анализ мировой смертности и прогнозирование трендов

Данный проект посвящен обработке демографических данных и попытке построения прогнозных моделей на основе исторических показателей смертности.

## 📌 Цели проекта
1.  **Предобработка данных:** Очистка "сырых" статистических данных и их конвертация в формат, пригодный для анализа.
2.  **Анализ лидеров:** Выявление стран с наиболее высокими показателями смертности за последние доступные периоды.
3.  **Моделирование:** Применение алгоритмов машинного обучения для поиска временных зависимостей.

## 🛠 Технологический стек
* **Python 3.x**
* **Pandas:** Для манипуляции данными и агрегации.
* **Matplotlib & Seaborn:** Для визуализации статистики.
* **Scikit-learn:** Для реализации модели линейной регрессии и оценки её точности.

## 🚀 Как работает проект

### 1. Подготовка (Data Wrangling)
Проект автоматически обрабатывает файл `data.csv`. Одной из ключевых задач является очистка столбцов `Number of Deaths` и `Death Rate`, где числовые значения представлены в виде текста с разделителями (запятыми). Код преобразует их в тип `float`.

### 2. Исследовательский анализ (EDA)
Программа фильтрует данные по последнему доступному году в наборе данных и группирует их по странам. На выходе мы получаем Топ-10 стран по количеству смертей.

### 3. Машинное обучение
В проекте используется модель **LinearRegression**. 
* **Входные данные (X):** Год исследования.
* **Целевая переменная (y):** Коэффициент смертности на 100 000 человек.
Модель обучается на 80% данных и тестируется на оставшихся 20%. Для оценки качества используется коэффициент детерминации ($R^2$).



## 📊 Результаты
Проект генерирует:
* График `top_deaths.png` с рейтингом стран.
* Визуализацию линии регрессии, показывающую тренд изменения смертности для выбранной страны.
